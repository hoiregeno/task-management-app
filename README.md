# Task Management App

A sleek, intuitive React + Vite web application built to help you organize your daily tasks efficiently. Quickly add new items, clear out completed tasks, and keep your lists perfectly sorted.

🚀 **[Live Demo](https://hoiregeno.github.io/task-management-app/)**

---

## ✨ Features

*   **Add Tasks:** Instantly add new items to your to-do list.
*   **Delete Tasks:** Keep your workspace clean by removing tasks as you finish them.
*   **Ordered Sorting:** Automatically or manually sort lists in order to maintain structural clarity.
*   **Blazing Fast:** Powered by Vite for lightning-fast Hot Module Replacement (HMR) and optimized builds.

---

## 🛠️ Tech Stack

*   **Frontend:** React (JavaScript)
*   **Build Tool:** Vite
*   **Styling:** CSS3
*   **Deployment:** GitHub Pages
